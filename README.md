# Objective

The objective of this lab is to understand the basic concepts of Object-Oriented Programming (OOP) by identifying real-world objects, designing UML Class Diagrams, and implementing Java programs using classes, objects, constructors, methods, and encapsulation.

---

# Project Overview

This lab consists of two Java projects:

## 1. CarDemo

The CarDemo project demonstrates how a real-world car can be represented as a Java class. It includes attributes, behaviors, object creation, and state changes.

### Attributes

* Brand
* Color
* Speed
* Engine Status
* Fuel Level
* Gear

### Behaviors

* startEngine()
* stopEngine()
* drive()
* moveFast()
* moveSlow()
* moveLeft()
* moveRight()
* turboMode()
* displayState()

Files:

* Car.java
* Main.java
* Car_UML.png

---

## 2. CalculatorDemo

The CalculatorDemo project demonstrates a simple calculator using methods for mathematical operations.

### Operations

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Average

The divide() method also handles division by zero correctly.

Files:

* Calculator.java
* Main.java
* Calculator_UML.png
